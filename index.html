Matvi Monitoring Agent

Agent de monitoring système pour Kubernetes

v0.1.5 Helm Chart Kubernetes

🚀 À propos

Agent permettant de récupérer les métriques système (CPU, mémoire, disque, réseau) et de les pousser vers une stack de monitoring externe (Prometheus Pushgateway).

✨ Fonctionnalités

📈 Métriques Kubernetes

Collecte automatique des métriques pour Kubernetes

🔄 Push Flexible

Compatible avec Push Gateway

⚡ Léger

Consommation minimale de ressources

📦 Installation

Ajoutez le dépôt Helm et installez le chart :

helm repo add matvi-charts https://MATVI-CONSULTING.github.io/monitoring-agent helm repo update helm install my-agent matvi-charts/matvi-monitoring-agent
